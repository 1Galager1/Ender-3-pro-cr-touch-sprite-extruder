# How to Get Your Firmware.bin File

**You asked for a firmware bin file for:**
- Ender 3 Pro
- V4.2.2 board
- CR Touch
- Sprite Pro extruder  
- 12864 screen

**Good news:** This repository is already configured for exactly this setup! 🎉

## Get Your Bin File in 3 Easy Steps

### Step 1: Go to Actions Tab
Click here → [**Actions**](../../actions/workflows/build.yml)

### Step 2: Run the Build
1. Click the **"Run workflow"** button (top right)
2. Make sure branch is set to **"main"**
3. Click the green **"Run workflow"** button
4. Wait 5-15 minutes for the build to complete ⏱️

### Step 3: Download Your Firmware
1. Click on the completed build (look for the green ✅)
2. Scroll to the bottom
3. Find **"Artifacts"** section
4. Click **"firmware-bin"** to download
5. Unzip the file - inside you'll find `firmware.bin`

## That's It! 

Now you can flash `firmware.bin` to your printer using an SD card.
